## 캠페인 개요
TerminalFix는 ClickFix 소셜엔지니어링 기법의 변종으로, 피해자를 Windows Run 대화상자 대신 Windows Terminal/PowerShell로 유도해 더 복잡한 다단계 스크립트를 실행시킨다. 손상된 정상 웹사이트에 가짜 Cloudflare Turnstile CAPTCHA를 띄워 PowerShell 명령을 클립보드에 심고, 이를 붙여넣도록 유도한다. 이후 DLL 사이드로딩, PNG 스테가노그래피, 광범위한 AD 정찰, 그리고 커스텀 역방향 터널 임플란트를 통한 지속적 네트워크 레벨 프록시 접근으로 이어지는 다단계 침투 체인이다. 이번 실행에서도 Microsoft 원문을 재확인했으나 인프라·해시 IOC는 전일 대비 변동이 없다. 검색에서 theregister.com, isc.sans.edu, scworld.com, redmondmag.com, rhisac.org, socprime.com, mallory.ai 등 7건의 신규 2차 보도 페이지가 노출되어 페치를 시도했으나 전부 프록시에 의해 차단되어 원문 검증에 실패했다.

## 공격 체인
1. 가짜 CAPTCHA 유도 — 손상된 사이트(예: `linked-log[.]com`)에 Cloudflare 로고·체크박스·스피너까지 모방한 가짜 Turnstile 오버레이 표시, "사람 확인" 명목으로 PowerShell 명령을 클립보드에 복사
2. 초기 페이로드 실행 — 피해자가 Windows Terminal/PowerShell에 명령을 붙여넣으면 녹색 텍스트로 가짜 "I am not a robot – Cloudflare ID: <16진수>" 확인 메시지를 출력하며 ZIP(`verify_pkg.zip`)을 다운로드해 `C:\ProgramData\<16-hex>\` (예: `C:\ProgramData\f47f2a8c21c9df4e`)에 압축 해제 후 `1.bat` 실행
3. DLL 사이드로딩 — 정상 서명된 `LockScreenContentServer.exe`(정상 위치: `C:\Windows\SystemApps`)가 자신의 디렉터리에서 악성 `dui70.dll`(PE 타임스탬프 2104년으로 위조, "Windows DirectUI Engine" 사칭)을 로드
4. 스테가노그래피 페이로드 — PNG 이미지 3장의 RGBA 픽셀 데이터에서 후속 단계 페이로드를 재조립
5. 지속성 — HKCU Run 키(`...\Run\LockScreenContentServer_MuODG5yBM`) 및 동일 이름의 예약 작업이 약 60분마다 `LockScreenContentServer.exe` 재실행, 페이로드 디렉터리는 hidden+system 속성
6. 내부 정찰 — `nltest`, `net group`, ADSI 쿼리로 도메인 트러스트/Domain Admins/AD 사용자·컴퓨터 열거, 내부 서버 추정 대상 핑 스윕. 정찰 스크립트는 영어·스페인어·독일어 로케일 변형을 지원(다국어 환경 대응 정황)
7. 비동기 명령 실행 — PowerShell 파일감시 루프가 텍스트 파일에서 명령을 읽어 `Invoke-Expression`으로 실행하고 결과를 별도 파일에 기록
8. 역방향 터널 — 공식 임베더블 Python 3.14.5 런타임으로 `pythonw.exe`가 `client.py`를 `--server`, `--uuid`, `cert.pem` 인자와 함께 실행, `/tunnel` WebSocket 경로로 `gitnow[.]dev:443`에 TLS(인증서 검증 비활성화) 연결. 7바이트 커스텀 바이너리 프레이밍(타입+스트림ID+길이)으로 하나의 WebSocket 위에 다중 TCP 연결 멀티플렉싱, 브라우저 User-Agent 4종 로테이션, keepalive, `MSG_SHUTDOWN`(`os._exit()`로 즉시 종료) 지원. 도달 가능한 내부 IPv4/IPv6/호스트명으로 임의 TCP 트래픽 중계

## 인접 캠페인 (참고)
- **DOUBLECUP** — 러시아계 Loader-as-a-Service. ClickFix 유인으로 브라우저 캐시에 스테가노그래피 PNG(BGRA 픽셀의 red 채널에 XOR 인코딩)를 심고 CountLoader 및 RAT `DeviceManager` 배포. TerminalFix와 무관한 별도 캠페인. TerminalFix IOC 목록에는 포함하지 않음.
- **CSO Online 보도 "fake Windows Update screens"** — 가짜 Windows 업데이트 화면을 이용한 별도 ClickFix 변종(스테가노그래피 + 인메모리 인포스틸러). 유인 화면(가짜 CAPTCHA가 아닌 가짜 Windows Update)과 페이로드가 달라 TerminalFix와 별개 캠페인으로 판단. IOC 공유하지 않음.
- **CrashFix** (2026-02, Microsoft) — ClickFix 변종으로 Python RAT를 배포. TerminalFix와 동일 계열(ClickFix → Windows Terminal 실행) 기법 트렌드 참고용이나 별도 캠페인이며 IOC는 공유하지 않음.
