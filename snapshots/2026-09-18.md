## 캠페인 개요
TerminalFix는 ClickFix 소셜엔지니어링 기법의 변종으로, 피해자를 Windows Run 대화상자 대신 Windows Terminal/PowerShell로 유도해 더 복잡한 다단계 스크립트를 실행시킨다. 손상된 정상 웹사이트에 가짜 Cloudflare Turnstile CAPTCHA를 띄워 PowerShell 명령을 클립보드에 심고, 이를 붙여넣도록 유도한다. 이후 DLL 사이드로딩, PNG 스테가노그래피, 광범위한 AD 정찰, 그리고 커스텀 역방향 터널 임플란트를 통한 지속적 네트워크 레벨 프록시 접근으로 이어지는 다단계 침투 체인이다. 인프라·해시 IOC는 전일 대비 변동 없음.

**⚠️ 주요 동향 (미검증, 중요):** 검색 스니펫(bankinfosecurity.com, heise.de, tech-insider.org, sectank.net 등, 원문 페치는 전부 차단)에 따르면 독일 연방정보보안청(BSI)이 2026-09-04 공식 보안공지를 통해 베를린 주(州) 정부 기관 네트워크 침해의 초기 침투 경로로 TerminalFix를 명시적으로 지목했고, 랜섬웨어 그룹 Rhysida가 이 침해를 통해 약 140만 건의 파일(인사기록, 신분증 스캔본, 병가 서류, 평문 비밀번호 목록 포함)을 다크웹에 공개했다고 한다. 베를린 시장 Kai Wegner는 몸값 지급을 거부했다고 알려짐. 이는 seed 베이스라인의 "관측되지 않음"(랜섬웨어·유출) 서술과 모순되지 않는다 — Microsoft의 원본 분석은 자사가 분석한 감염 체인 범위에 한정된 서술이며, 이번 건은 별도의 실제 피해 사례(BSI 공식 확인)로 보인다. 근거 사이트가 전부 프록시 차단되어 원문 미확인 상태이므로 provenance는 unverified로 유지.

## 공격 체인
1. 가짜 CAPTCHA 유도 — 손상된 사이트(예: `linked-log[.]com`)에 Cloudflare 로고·체크박스까지 모방한 가짜 Turnstile 오버레이 표시, "사람 확인" 명목으로 PowerShell 명령을 클립보드에 복사
2. 초기 페이로드 실행 — 피해자가 Windows Terminal/PowerShell에 명령을 붙여넣으면 ZIP(`verify_pkg.zip`)을 다운로드해 `C:\ProgramData\<16-hex>\` (예: `C:\ProgramData\f47f2a8c21c9df4e`)에 압축 해제 후 `1.bat` 실행
3. DLL 사이드로딩 — 정상 서명된 `LockScreenContentServer.exe`(정상 위치: `C:\Windows\SystemApps`)가 자신의 디렉터리에서 악성 `dui70.dll`("Windows DirectUI Engine" 사칭)을 로드
4. 스테가노그래피 페이로드 — PNG 이미지 3장의 RGBA 픽셀 데이터에서 후속 단계 페이로드를 재조립
5. 지속성 — HKCU Run 키 및 동일 이름의 예약 작업이 약 60분마다 `LockScreenContentServer.exe` 재실행, 페이로드 디렉터리는 hidden+system 속성
6. 내부 정찰 — `nltest`, `net group`, ADSI 쿼리로 도메인 트러스트/Domain Admins/AD 사용자·컴퓨터 열거, 내부 서버 추정 대상 핑 스윕
7. 비동기 명령 실행 — PowerShell 파일감시 루프가 텍스트 파일에서 명령을 읽어 `Invoke-Expression`으로 실행하고 결과를 별도 파일에 기록
8. 역방향 터널 — 공식 임베더블 Python 3.14.5 런타임으로 `pythonw.exe`가 `client.py`를 `--server`, `--uuid`, `cert.pem` 인자와 함께 실행, `gitnow[.]dev:443`에 TLS/WebSocket으로 연결, 도달 가능한 내부 IPv4/IPv6/호스트명으로 임의 TCP 트래픽 중계
