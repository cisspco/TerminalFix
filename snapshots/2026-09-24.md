## 캠페인 개요
TerminalFix는 손상된 정상 사이트에 삽입된 가짜 Cloudflare Turnstile CAPTCHA로 시작해, 피해자가 클립보드에 복사된 PowerShell 명령을 Windows Terminal/PowerShell에 붙여넣도록 유도하는 ClickFix 변종이다(T1204.004). 이후 정상 서명된 `LockScreenContentServer.exe`에 악성 `dui70.dll`을 사이드로딩하고, PNG 이미지의 픽셀 데이터에 스테가노그래피로 숨긴 페이로드를 재조립하여 실행한다. 지속성은 HKCU Run 키와 약 60분 주기 예약 작업(`LockScreenContentServer_MuODG5yBM`)으로 확보되며, 이후 AD 정찰과 함께 Python 기반 커스텀 역방향 WebSocket 터널(`gitnow[.]dev:443`)을 통해 공격자에게 내부망 접근을 제공한다. 오늘 재확인한 Microsoft 원문은 변경 사항이 없으며, 기존 baseline과 동일하다.

## 공격 체인
1. 가짜 CAPTCHA 유도 — 손상된 사이트(`linked-log[.]com`)에 삽입된 가짜 Cloudflare Turnstile 오버레이가 클립보드에 악성 PowerShell 명령을 복사
2. 초기 페이로드 실행 — 사용자가 명령을 Windows Terminal/PowerShell에 붙여넣으면 ZIP(`verify_pkg.zip`)을 내려받아 `C:\ProgramData\<16진수>\`에 압축 해제 후 `1.bat` 실행
3. DLL 사이드로딩 — 정상 서명된 `LockScreenContentServer.exe`가 동일 디렉터리의 악성 `dui70.dll`을 로드(정상 경로는 `C:\Windows\SystemApps`)
4. 스테가노그래피 페이로드 — PNG 3장의 RGBA 픽셀 데이터에서 실행 파일/DLL 조각을 재조립
5. 지속성 — HKCU Run 키 및 예약 작업(`LockScreenContentServer_MuODG5yBM`, 약 60분 주기)으로 재실행, 스테이징 디렉터리에 hidden+system 속성 부여
6. 내부 정찰 — `nltest`, `net group`, ADSI 쿼리(도메인 트러스트, Domain Admins, AD 사용자/컴퓨터), 내부 서버 핑 스윕
7. 비동기 명령 실행 — PowerShell 파일감시 루프가 텍스트 파일에서 명령을 읽어 `Invoke-Expression`으로 실행, 결과를 다른 파일에 기록
8. 역방향 터널 — 임베더블 Python 3.14.5 런타임으로 `pythonw.exe`가 `client.py --server --uuid cert.pem` 실행, TLS/WebSocket으로 `gitnow[.]dev:443`에 연결해 내부 IPv4/IPv6/호스트명으로 임의 TCP 릴레이
