## 캠페인 개요
변동 없음 — 전날과 동일. TerminalFix는 ClickFix 변종으로, 가짜 Cloudflare Turnstile CAPTCHA가 클립보드에 PowerShell 명령을 복사시켜 Windows Terminal/PowerShell에 붙여넣도록 유도한다. 이후 ZIP 다운로드 → DLL 사이드로딩 → PNG 스테가노그래피 추가 페이로드 → 레지스트리/예약 작업 지속성 → AD 정찰 → Python 기반 역방향 WebSocket 터널(`gitnow[.]dev:443`)로 이어진다. Microsoft 원본 포스트는 권한 상승·보안 통제 무력화·탈취·랜섬웨어를 "관찰하지 않음"이라고 명시하며, 이번 재확인에서도 동일하게 유지된다.

## 공격 체인
1. 가짜 CAPTCHA 유도 — 손상된 정상 사이트(`linked-log[.]com`)에 가짜 Cloudflare Turnstile 오버레이를 띄워 "I am not a robot" 검증을 가장, PowerShell 명령을 클립보드에 몰래 복사
2. 초기 페이로드 실행 — 피해자가 Windows Terminal/PowerShell에 붙여넣으면 ZIP(`verify_pkg.zip`)을 다운로드해 `C:\ProgramData\<16-hex>\`에 압축 해제 후 `1.bat` 실행, 가짜 녹색 텍스트 확인 메시지 출력
3. DLL 사이드로딩 — 정상 서명된 `LockScreenContentServer.exe`(정상 위치는 `C:\Windows\SystemApps`)가 같은 디렉터리의 악성 `dui70.dll`을 로드
4. 스테가노그래피 페이로드 — PNG 이미지 3장의 RGBA 픽셀 데이터에서 후속 단계 페이로드 재조립
5. 지속성 — HKCU Run 키(`LockScreenContentServer_MuODG5yBM`) + 동일 이름의 예약 작업이 약 60분마다 `LockScreenContentServer.exe` 재실행, 페이로드 디렉터리에 hidden+system 속성 부여
6. 내부 정찰 — `nltest`, `net group`, ADSI 질의(도메인 트러스트, Domain Admins, AD 사용자/컴퓨터), 내부 서버 ping 스윕; 정찰 스크립트는 영어/스페인어/독일어 로캘 변형 포함
7. 비동기 명령 실행 — PowerShell 파일-감시 루프가 텍스트 파일에서 명령을 읽어 `Invoke-Expression`으로 실행, 결과를 다른 파일에 기록
8. 역방향 터널 — 공식 임베디드 Python 3.14.5 런타임의 `pythonw.exe`가 `client.py --server --uuid cert.pem`을 실행, `gitnow[.]dev:443`으로 TLS/WebSocket 역방향 터널 수립(`/tunnel` 업그레이드 경로, TLS 인증서 검증 비활성화, 7바이트 커스텀 프레이밍, 내부 IPv4/IPv6/호스트명으로 임의 TCP 릴레이)
