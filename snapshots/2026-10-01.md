## 캠페인 개요
변동 없음. TerminalFix는 ClickFix 계열의 사회공학 기법으로, 손상된 사이트에 게시된 가짜 Cloudflare Turnstile CAPTCHA가 피해자의 클립보드에 악성 PowerShell 명령을 주입하고 Windows Terminal/PowerShell에 붙여넣도록 유도한다. 이후 ZIP 다운로드 → 정상 서명된 `LockScreenContentServer.exe`를 이용한 DLL 사이드로딩(`dui70.dll`) → PNG 스테가노그래피로 후속 스테이지 재조립 → 레지스트리/예약 작업 지속성 → AD/네트워크 정찰 → Python 기반 역방향 WebSocket 터널(`gitnow[.]dev:443`)을 통한 내부망 피벗 순으로 진행된다. Microsoft 원문을 이번 실행에서도 재확인했으며 신규 인프라·해시·IOC는 없었다.

## 공격 체인
1. 가짜 CAPTCHA 유도 — 손상된 사이트(`linked-log[.]com`)에 가짜 Cloudflare Turnstile 오버레이가 표시되고, 상호작용 시 악성 PowerShell 명령이 클립보드에 복사됨 (T1204.004)
2. 초기 페이로드 실행 — 피해자가 Windows Terminal/PowerShell에 명령을 붙여넣으면 가짜 녹색 텍스트 인증 메시지(예: "Cloudflare ID: f47f2a8c21c9df4e")가 출력되며 ZIP이 다운로드되어 `C:\ProgramData\<16-hex>\`에 압축 해제, `1.bat` 실행
3. DLL 사이드로딩 — 정상 서명된 `LockScreenContentServer.exe`(정상 위치는 `C:\Windows\SystemApps`)가 동일 디렉터리의 악성 `dui70.dll`을 로드. DLL의 PE 타임스탬프는 2104년으로 위조됨
4. 스테가노그래피 페이로드 — PNG 이미지 3개의 RGBA 픽셀 데이터에서 후속 스테이지를 재조립
5. 지속성 — `HKCU\...\Run\LockScreenContentServer_MuODG5yBM` 레지스트리 키 및 동일 이름의 예약 작업이 약 60분마다 `LockScreenContentServer.exe` 재실행, 페이로드 디렉터리에 hidden+system 속성 부여
6. 내부 정찰 — `nltest`, `net group`, ADSI 쿼리(도메인 트러스트, Domain Admins, AD 사용자/컴퓨터), 내부 서버 ping sweep. 정찰 스크립트는 영어/스페인어/독일어 로캘 변형 포함
7. 비동기 명령 실행 — PowerShell 파일 감시 루프가 텍스트 파일에서 명령을 읽어 `Invoke-Expression`으로 실행하고 결과를 별도 파일에 기록
8. 역방향 터널 — 공식 임베더블 Python 3.14.5 런타임의 `pythonw.exe`가 `client.py --server --uuid cert.pem`을 창 없이 실행, TLS 인증서 검증 비활성화(`CERT_NONE`) 상태로 `gitnow[.]dev:443`에 TLS/WebSocket(`/tunnel` 경로) 연결. 7바이트 커스텀 프레이밍 헤더로 다중 TCP 스트림을 멀티플렉싱, `MSG_SHUTDOWN` 시 `os._exit()`로 강제 종료, 4종의 브라우저 User-Agent를 세션별로 로테이션
