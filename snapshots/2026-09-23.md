## 캠페인 개요
변동 없음. TerminalFix는 ClickFix 계열 변종으로, 손상된 정상 사이트에 가짜 Cloudflare Turnstile CAPTCHA를 띄워 피해자가 PowerShell에 명령어를 붙여넣도록 유도한다. 이후 ZIP 다운로드 → `LockScreenContentServer.exe`의 `dui70.dll` DLL 사이드로딩 → PNG 스테가노그래피 페이로드 → 레지스트리/예약작업 지속성 → AD 정찰 → `gitnow[.]dev`로의 커스텀 Python 역방향 WebSocket 터널로 이어지는 다단계 침투 체인을 사용한다. Microsoft 원본 게시물을 재확인했으나 IOC·인프라·타임라인 변경 사항은 없었다. 이번 실행에서는 기존에 추적 중인 Berlin/BSI/Rhysida 서사에 대한 검색 스니펫이 이전보다 더 구체적이고 (표면상) 신뢰도 높은 출처(heise.de, 독일 공영 tagesspiegel.de, BSI 공식 PDF 자체)에서 나왔으나, 7건의 원문 페치 시도가 전부 프록시에 차단되어 여전히 직접 검증되지 않았다.

## 공격 체인
1. 가짜 CAPTCHA 유도 — 손상된 정상 사이트(`linked-log[.]com` 등)에 가짜 Cloudflare Turnstile 오버레이 표시, "I am not a robot" 체크 유도 → 클립보드에 PowerShell 명령 복사
2. 초기 페이로드 실행 — 사용자가 PowerShell/Windows Terminal에 붙여넣기 → ZIP(`verify_pkg.zip`) 다운로드, `C:\ProgramData\<16진수>\`에 추출, `1.bat` 실행
3. DLL 사이드로딩 — 정상 서명된 `LockScreenContentServer.exe`(정상 경로 `C:\Windows\SystemApps` 외 실행 시 이상 징후)가 동일 폴더의 악성 `dui70.dll` 로드
4. 스테가노그래피 페이로드 — PNG 3개의 RGBA 픽셀 데이터에서 실행파일 및 DLL 조각 재조립, 디스크에 쓰지 않고 메모리에서 복호화
5. 지속성 — HKCU Run 키 + 예약 작업으로 약 60분마다 `LockScreenContentServer.exe` 재실행, 페이로드 디렉터리 hidden+system 속성
6. 내부 정찰 — `nltest`, `net group`, ADSI 쿼리(도메인 신뢰, Domain Admins, AD 사용자/컴퓨터), 내부 서버 핑 스윕
7. 비동기 명령 실행 — PowerShell 파일감시 루프가 텍스트 파일에서 명령을 읽어 `Invoke-Expression`으로 실행, 결과를 별도 파일에 기록
8. 역방향 터널 — 임베더블 Python 3.14.5 런타임의 `pythonw.exe`가 `client.py --server --uuid cert.pem` 실행, TLS/WebSocket으로 `gitnow[.]dev:443`에 연결해 내부망 임의 TCP 트래픽 중계
